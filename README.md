# SkyCast – Weather Information App

## Project Description
SkyCast is a Python-based weather information web application developed as part of my Python Development Internship at Auspify Technologies. It allows users to search for a city and view its current weather information and forecast.

## Features
- Search for cities around the world.
- View current weather conditions.
- Display temperature and other weather details.
- View a 5-day weather forecast.
- Switch between Celsius and Fahrenheit.
- Responsive interface for different screen sizes.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Open-Meteo Weather API

## Requirements
- Python 3
- Flask
- Requests
- Gunicorn
- Internet connection

## How to Run the Project
1. Open the project folder in Terminal.
2. Create and activate a Python virtual environment.
3. Install the required packages:

   `pip install -r requirements.txt`

4. Start the application:

   `python app.py`

5. Open the local address shown in Terminal in your browser.

## Project Structure
- `app.py` – Main Flask application.
- `requirements.txt` – Required Python packages.
- `templates/index.html` – Website webpage.
- `static/style.css` – Website styling.
- `static/script.js` – Weather search and display logic.
- `static/manifest.json` – Web app manifest.
- `README.md` – Project documentation.
